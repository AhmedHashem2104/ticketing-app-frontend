# Mock imagery

Images used by the mock API's seeded data (events, team crests, profile photos). The API returns
these as same-origin paths (`/images/...`), so they pass the app's `img-src 'self'` CSP and work offline.

- `events/*.jpg` — 960×540 crops of CC0 photos from [StockSnap](https://stocksnap.io) (no attribution required; credited anyway).
- `teams/*.svg` — crests and flag badges drawn for the fictional clubs in the seed data.
- `avatars/*.jpg` — placeholder portraits from [randomuser.me](https://randomuser.me) for seed accounts.
